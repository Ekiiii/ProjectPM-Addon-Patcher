## 🇬🇧 English

### Overview
**ProjectPM Addon Patcher** allows players to easily install, update, and manage community addons for Pokémon Platinum multiplayer (Project PM), without risking ROM corruption or dealing with fragile xDelta checksum errors.

### Features
- **Smart Direct Injection Engine**: Injects C mods cleanly into the Nitro-SDK Autoload Table and high arena memory. Zero xDelta checksum mismatch errors, works on any ROM configuration!
- **Soul Link / SoulLocke Edition**: Full support for shared fates, automated graveyard PC boxes, single shared catch per area, and live streamer overlay.
- **Visual+ Options**:
  - *Visual+ Battle Backgrounds*: High-definition redrawn battle scenes (`Built-in` / `Off`).
  - *Visual+ 3D Camera*: Closer overworld perspective for an enhanced 3D look (`Built-in` / `Off`).
- **One-Click Reversible**: Easily revert to clean stock ProjectPM at any time.
- **Save & Randomizer Protection**: Automatically preserves companion save files (`.dsv`) and `.rand.txt` seeds.
- **Bilingual Interface**: Full English and French support with instant in-app switching.
- **Standalone Portable `.exe`**: No Python installation required for players!
